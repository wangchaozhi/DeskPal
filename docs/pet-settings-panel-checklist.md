# 宠物配置可视化面板开发清单

## 第一阶段：基础管理面板

- [x] 从托盘菜单打开配置面板。
- [x] 在 QML 中新增独立设置窗口，不影响桌宠透明窗口。
- [x] 显示当前扫描到的宠物列表。
- [x] 展示宠物 `id`、`name`、`type`、`renderer`、`source`、`basePath`。
- [x] 支持从面板切换当前宠物。
- [x] 显示基础 2D/3D 预览区域。
- [x] 保持现有 `ActionController` 动作驱动预览。

## 第二阶段：2D 配置编辑

- [x] 支持选择 2D 渲染器：`qml`、`svg`、`gif`、`apng`、`png-sequence`。
- [x] 支持动作预览：`idle`、`happy`、`sleepy`、`dragging`（面板预览独立于桌宠窗口）。
- [x] 支持选择动作资源：`idle`、`happy`、`sleepy`、`dragging`。
- [x] 支持配置 PNG 序列帧帧率（`fps`）。
- [x] 支持配置缩放、窗口尺寸（`scale`、`width`、`height`）。
- [x] 支持保存或生成 `pet.json`。

## 第三阶段：3D 配置编辑

- [x] 支持选择 `.glb/.gltf` 或 Qt Quick 3D QML。
- [x] 2D 与 3D 专属编辑区拆分为独立 QML 组件。
- [ ] 支持配置模型缩放、旋转、位置。
- [ ] 支持配置相机距离和灯光参数。
- [x] 支持动作到动画片段的映射（`animations`）。
- [ ] 支持骨骼动画预览。

## 第四阶段：导入导出

- [x] 支持选择本地资源目录。
- [x] 支持基础资源校验和缺失提示。
- [x] 支持示例宠物包。
- [ ] 支持更完整的资源校验规则。
- [x] 支持导入宠物包。
- [x] 支持导出可分享宠物包。
- [ ] 支持示例宠物包生成。

## 应用级设置

- [x] 桌宠不透明度调节。
- [x] Windows 开机自启开关。
- [x] 左键点击弹出语音气泡（`speeches` 可配置）。
- [x] 随机 idle 动作列表可配置（`idleActions`）。
