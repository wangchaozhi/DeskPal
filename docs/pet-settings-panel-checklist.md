# 宠物配置可视化面板开发清单

## 第一阶段：基础管理面板

- [x] 从托盘菜单打开配置面板。
- [x] 在 QML 中新增独立设置窗口，不影响桌宠透明窗口。
- [x] 显示当前扫描到的宠物列表。
- [x] 展示宠物 `id`、`name`、`type`、`renderer`、`source`、`basePath`。
- [x] 支持从面板切换当前宠物。
- [x] 显示基础 2D/3D 预览区域。
- [x] 保持现有 `ActionController` 动作驱动预览。

## 第二阶段：2D 配置编辑

- [ ] 支持选择 2D 渲染器：`qml`、`svg`、`gif`、`apng`、`png-sequence`。
- [ ] 支持选择动作资源：`idle`、`happy`、`sleepy`、`dragging`。
- [ ] 支持配置 PNG 序列帧帧率。
- [ ] 支持配置缩放、偏移和窗口尺寸。
- [ ] 支持保存或生成 `pet.json`。

## 第三阶段：3D 配置编辑

- [ ] 支持选择 `.glb/.gltf` 或 Qt Quick 3D QML。
- [ ] 支持配置模型缩放、旋转、位置。
- [ ] 支持配置相机距离和灯光参数。
- [ ] 支持动作到动画片段的映射。
- [ ] 支持骨骼动画预览。

## 第四阶段：导入导出

- [ ] 支持选择本地资源目录。
- [ ] 支持资源校验和缺失提示。
- [ ] 支持导入宠物包。
- [ ] 支持导出可分享宠物包。
- [ ] 支持示例宠物包生成。
